# 02: 굴림 연출 ①: 미리 굴리기 → 면 맞추기 → 재생 (위험 검증)

**What to build:** 굴림 버튼을 누르면 주사위가 3D 판 위에서 실제처럼 굴러가고 부딪히다 멈추며, 멈췄을 때 위를 향한 눈이 게임 엔진이 정한 굴림 결과와 정확히 같다. 스펙에서 가장 위험한 부분이라 일찍 검증한다. 컵과 정렬 줄로 떠오르는 동작은 08에서 한다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 화면 밖에서 물리 시뮬레이션을 미리 돌려 궤적과 멈춘 자세를 얻는다 → 멈췄을 때 위를 향한 면이 굴림 결과의 눈이 되도록 주사위 모델의 면 배치를 돌려 맞춘다 → 같은 궤적을 화면에서 재생한다.
- [ ] "멈춘 뒤 위를 향한 면 = 굴림 결과"를 확인하는 방법을 정하고 자동 테스트로 남긴다. 면 맞추기를 검증하는 것이며, 멈춘 면을 읽어 점수에 반영하는 코드는 만들지 않는다(ADR-0001).
- [ ] 연출 입구는 멈춤 시점과 정렬 끝 시점을 알린다. 이 티켓에는 정렬 애니메이션이 없으므로, 멈춘 직후 주사위를 정렬 줄로 순간 배치하고 정렬 끝을 알린다. 굴림 버튼부터 정렬 끝까지 조작이 잠긴다.
- [ ] 같은 굴림 결과를 여러 번 넣어도 매번 면이 맞는다(모서리로 서거나 판 밖으로 나가는 경우 포함).
- [ ] 01이 만든 굴림 연출 입구의 구현만 바꿔 끼운다. 엔진·점수표·보이지 않는 버튼은 바뀌지 않는다. 01의 순간 배치 경로는 '동작 줄이기'용으로 그대로 남는다.
- [ ] 홀드 자리의 주사위는 굴리지 않는다(04가 먼저 끝났든 아니든 홀드 상태를 따른다).
- [ ] 판단 기준: 굴러가는 모습이 어색하거나 면 맞추기가 불안정하면 물리 엔진 없는 직접 만든 애니메이션으로 내려간다. 어느 쪽으로 갈지는 화면을 사용자에게 보여 주고 확인받는다.
