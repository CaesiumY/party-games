# 08: 굴림 연출 ②: 컵 → 쏟기 → 정렬로 떠오르기

**What to build:** 굴림 버튼을 누르면 정렬 줄의 주사위가 컵에 들어가고, 컵이 흔들리다 판에 쏟는다. 주사위는 02의 방식으로 굴러가 멈춘 뒤, 떠올라 정렬 줄에 오름차순으로 늘어선다. 홀드 자리의 주사위는 그동안 움직이지 않는다. 홀드하거나 풀 때, 3번째 굴림 뒤 홀드 자리로 올라갈 때도 순간 이동 대신 움직여서 옮겨 간다. 기기의 '동작 줄이기' 설정이 켜져 있으면 04의 순간 배치 그대로 보인다.

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] 한 번의 굴림 연출이 컵 → 굴러감 → 정렬 순서로 진행된다. 다시 굴린 주사위는 자기들끼리만 정렬하고 홀드 자리와 섞지 않는다.
- [ ] 연출 입구가 멈춤 시점(점수 미리보기 표시)과 정렬 끝 시점(조작 잠금 해제)을 정확히 알린다. 그 사이에는 굴림·홀드·기록이 막힌다.
- [ ] 홀드·홀드 풀기·3번째 굴림 뒤 이동이 애니메이션으로 옮겨 간다. 이동 중에는 조작이 막힌다.
- [ ] 01이 감지한 '동작 줄이기' 설정이 켜져 있으면 컵과 굴러감을 건너뛰고 정렬 줄에 바로 놓는다.
- [ ] 연출 입구 외의 모듈(엔진, 점수표, 보이지 않는 버튼)은 바뀌지 않는다.
- [ ] 02의 "멈춘 뒤 위를 향한 면 = 굴림 결과" 테스트가 계속 통과한다.
