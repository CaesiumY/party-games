# 05: 연습 모드 한 판 완주, 최소 시작 화면, 최고 점수

**What to build:** 시작 화면에서 혼자 시작하면 연습 모드로 12턴을 끝까지 할 수 있다. 화면 위쪽에 "턴 n/12"가 보인다. 마지막 기록 뒤 결과 화면이 떠서 이번 총합 득점과 이 기기의 최고 점수를 비교하고, 넘었으면 새 최고 점수를 저장하고 알린다. 결과 화면에서 "같은 멤버로 다시"와 "처음으로"를 고를 수 있다.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 엔진: 12턴 뒤 게임 종료, 종료 후 명령 거부(TDD).
- [ ] 최소 시작 화면: 1인으로 시작하는 버튼과 이 기기의 최고 점수 표시. 인원·이름·색 입력은 06에서 이 화면에 덧붙인다.
- [ ] 결과 화면: 이번 총합 득점, 최고 점수, 새 최고 점수 여부. "같은 멤버로 다시"는 같은 설정으로 바로 새 게임을, "처음으로"는 시작 화면을 연다.
- [ ] 브라우저 저장 도우미를 만든다: 항목(키)마다 따로 버전 번호를 두고, 읽을 수 없거나 버전이 다른 항목만 버린다. 최고 점수가 이 도우미를 쓴다. 07(이어 하기)과 09(음소거)도 이 도우미를 재사용한다.
- [ ] 연습 모드와 대전 모드는 따로 저장하지 않고 플레이어 수에서 계산한다.
