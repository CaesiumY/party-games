# 16: 배포 (Vercel)

**What to build:** 완성된 MVP를 Vercel 정적 호스팅에 올려, 링크 하나로 누구나 휴대폰 브라우저에서 바로 플레이할 수 있게 한다.

**Blocked by:** 11, 14, 그리고 사용자의 배포 승인

**Status:** ready-for-human — MVP가 완성된 뒤 사용자가 명시적으로 승인해야만 진행한다. 배포는 외부에 공개되는 작업이다.

- [ ] 배포 전에 사용자에게 무엇을 어디에 올리는지 보여 주고 승인을 받는다.
- [ ] 운영 빌드에 테스트용 주사위 공급원이 없음을 다시 확인한다.
- [ ] 배포된 주소에서 휴대폰으로 연습 모드 한 판과 대전 모드 한 판을 끝까지 해 본다.
- [ ] 배포 주소를 저장소에 기록한다.
