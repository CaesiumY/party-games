# 07: 이어 하기

**What to build:** 게임 도중 새로고침하거나 탭을 닫았다 다시 열어도 같은 턴, 같은 점수표, 같은 주사위와 홀드 상태에서 이어 할 수 있다. 이어 할 게임이 있으면 시작 화면에서 "이어 하기"와 "새 게임"을 고른다. 끝난 게임은 이어 하기 대상에서 사라진다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 진행 중 게임 상태가 바뀔 때마다 05의 저장 도우미로 저장하고, 앱을 시작할 때 읽는다. 진행 중 게임 항목의 버전이 맞지 않으면 그 항목만 버린다(최고 점수는 유지).
- [ ] 굴림 결과는 굴림 명령 시점에 저장된다. 굴림 연출 도중 새로고침해도 결과가 바뀌지 않는다(새로고침으로 다시 굴리지 못함).
- [ ] 연출 진행 중 여부는 저장하지 않는다. 복원하면 주사위는 정렬이 끝난 상태로 놓이고 조작이 잠기지 않는다.
- [ ] 저장했다가 복원한 게임을 이어서 끝까지 진행하면, 끊기지 않은 게임과 같은 결과가 나온다(엔진 테스트).
- [ ] 게임이 끝나면 진행 중 게임 데이터를 지운다.
- [ ] 1인 게임과 2~4인 게임 모두 이어 하기가 동작한다.
