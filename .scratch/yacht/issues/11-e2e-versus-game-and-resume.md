# 11: E2E: 2인 대전 한 판과 이어 하기

**What to build:** Playwright 자동 테스트 하나가 브라우저에서 2인 대전 한 판을 처음부터 끝까지 진행한다. 중간에 새로고침해서 이어 하기를 확인하고, 결과 화면의 순위까지 본다.

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] 테스트용 빌드에서만 테스트용 주사위 공급원을 쓴다. 이 공급원의 눈은 (플레이어, 턴, 굴림 번호)만으로 정해져서, 새로고침 뒤에도 같은 눈이 나온다.
- [ ] 운영 빌드 결과물에 테스트용 공급원이 들어 있지 않음을 검사한다(빌드 산출물에서 표식 문자열 검색 등).
- [ ] '동작 줄이기'를 켜서 굴림 연출을 건너뛴다.
- [ ] 화면 없이 도는 브라우저에서 WebGL이 켜지도록 실행 옵션을 정하고, 테스트 첫 단계에서 3D 캔버스가 떴는지 확인한다(WebGL 미지원 안내가 뜨면 실패).
- [ ] 홀드는 보이지 않는 주사위 버튼으로, 카테고리 선택은 용어집 표기의 카테고리 이름으로 찾는다.
- [ ] 게임 도중 새로고침 → "이어 하기" → 같은 턴·점수표에서 계속 → 끝까지 진행 → 결과 화면의 순위 확인.
- [ ] CI(15)가 이미 있으면 E2E를 CI에 추가한다. 없으면 15가 추가한다.
