# 03: 12개 카테고리 점수와 점수 미리보기

**What to build:** 점수표에 12개 카테고리, 소계("47/63" 형태), 보너스+35, 총합 득점이 보인다. 굴림 뒤 빈 카테고리마다 점수 미리보기가 흐리게 뜨고, 카테고리를 탭해 선택한 뒤 "기록" 버튼으로 기록한다. 성립하지 않는 카테고리를 선택하면 버튼이 "0점으로 기록"이 된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 12개 카테고리의 점수 계산이 스펙의 표를 따른다(TDD). 경계 사례: 66666을 풀 하우스에 넣으면 30, 포 다이스 5개 일치, 12345가 S. 스트레이트로도 성립, 11234 같은 중복이 섞인 스트레이트, 스크래치 0점.
- [ ] 윗칸 보너스: 소계 62면 보너스 없음, 63이면 +35.
- [ ] 점수 미리보기와 실제 기록은 같은 계산을 쓴다(미리보기 값 = 기록 값을 테스트).
- [ ] 이미 기록한 카테고리에 다시 기록하면 거부된다. 첫 굴림 뒤에는 남은 굴림이 있어도 언제든 기록할 수 있다.
- [ ] 정해진 눈으로 12턴을 진행해 총합 득점 325점이 나오는 테스트가 있다.
- [ ] 카테고리 탭 → 선택 상태 강조 → "기록" 버튼의 두 단계다. 다른 카테고리를 탭하면 선택이 옮겨 간다. 굴림 버튼을 누르면 선택은 지워진다. 언두는 없다.
- [ ] 카테고리 이름과 줄 이름이 용어집 표기와 똑같다(에이스 … 요트, 소계, 보너스+35, 총합 득점).
- [ ] 점수 미리보기는 굴림 연출 입구의 멈춤 시점에 나타난다.
- [ ] 점수표는 플레이어 N열을 받는다. 4열 임시 데이터로 375×667 세로 화면에서 3D 판·점수표·버튼이 스크롤 없이 들어오는지 확인한다.
