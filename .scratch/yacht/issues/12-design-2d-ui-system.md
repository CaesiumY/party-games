# 12: 디자인 ① 2D UI 디자인 체계

**What to build:** 점수표, 버튼, 시작·결과 화면, 차례 배너, 성립 알림 문구 같은 2D UI에 일관된 디자인(색, 글꼴, 간격, 모양)을 입힌다. 먼저 서로 다른 시안 2~3개를 보여 드리고, 고르신 방향으로 디자인 문서를 만들어 적용한다.

**Blocked by:** 06, 07, 10

**Status:** ready-for-agent

> 중간에 사용자가 시안을 고르는 관문이 있다.

- [ ] 작업 시작 시 요청이 없어도 `/design-consultation` 으로 서로 다른 시안 2~3개(글꼴·색 미리보기 포함)를 먼저 보여 준다. 여러 시안을 한꺼번에 뽑는 `/design-shotgun` 은 사용자 전용이므로, 원하면 사용자가 직접 실행한다는 안내만 한다.
- [ ] 사용자의 선택과 그 이유를 기록한다.
- [ ] 고른 방향으로 디자인 문서(`DESIGN.md`)를 만들고 2D UI 전체에 적용한다.
- [ ] 375×667 세로 화면, 4인 대전에서도 스크롤 없이 한 화면에 들어온다.
- [ ] 음소거 버튼은 09가 끝난 뒤 14(검수)에서 맞춘다.
