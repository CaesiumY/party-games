# 04: 정렬 줄과 홀드 자리, 3번 굴림

**What to build:** 굴림이 멈추면 주사위가 판 가운데 정렬 줄에 눈 오름차순으로 놓인다. 정렬 줄의 주사위를 탭하면 판 위쪽 홀드 자리로 올라가고, 홀드 자리의 주사위를 탭하면 정렬 줄로 돌아온다. 한 턴에 3번까지 굴릴 수 있고, 남은 굴림이 "앞으로 n번"으로 보인다. 3번째 굴림이 끝나면 남은 주사위가 저절로 홀드 자리로 올라간다. 이 티켓에서는 애니메이션 없이 순간 배치한다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 엔진: 홀드 토글, 첫 굴림 전 홀드 거부, 4번째 굴림 거부, 홀드한 주사위는 다시 굴려도 눈 유지, 5개 모두 홀드하면 굴림 불가, 새 턴에서 홀드 초기화(TDD). 홀드를 바꿔도 주사위 정체성이 유지된다.
- [ ] 정렬 줄과 홀드 자리는 각각 눈 오름차순이다. 홀드하거나 풀 때마다 양쪽을 다시 정렬한다. 다시 굴린 주사위는 홀드 자리와 섞지 않는다. 배치 순서는 화면이 정하며 엔진은 순서를 저장하지 않는다.
- [ ] 홀드는 굴림 연출 입구의 정렬 끝 이후에만 고를 수 있다.
- [ ] 탭 판정 영역이 주사위보다 넉넉하다. 데스크톱의 마우스 클릭도 같은 방식으로 동작한다.
- [ ] 5개 모두 홀드하면 굴림 버튼이 비활성화된다.
- [ ] 3번째 굴림 뒤 정렬 줄의 주사위가 홀드 자리로 올라가고 굴림 버튼이 사라진다. 이는 표현일 뿐 엔진에 홀드 토글을 보내지 않는다. 이때는 주사위 탭과 보이지 않는 버튼의 홀드 토글이 꺼진다.
- [ ] 보이지 않는 주사위 버튼 5개가 화면과 같은 순서(홀드 자리, 그다음 정렬 줄, 각각 오름차순)로 눈과 홀드 여부를 읽어 주고, 누르면 홀드를 토글한다. 3D 탭과 같은 저장소 명령을 쓴다. 3번째 굴림 뒤에는 홀드 토글만 꺼지고 눈은 계속 읽어 준다(기여 주사위 여부 읽기는 10이 덧붙인다).
