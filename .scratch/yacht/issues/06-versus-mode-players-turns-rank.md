# 06: 대전 모드: 인원·이름·색, 차례, 순위

**What to build:** 시작 화면에서 인원을 1~4명 고르고 이름을 입력해(비우면 "플레이어 n") 시작한다. 2~4명이면 대전 모드다. 기록이 끝나면 다음 플레이어 차례가 되고 "다음은 ○○ 차례" 배너가 잠깐 떴다 사라진다. 모든 플레이어의 점수표가 한 화면에 보이고 현재 차례의 열이 강조된다. 게임이 끝나면 결과 화면에 총합 득점 순위가 나오며, 동점이면 같은 순위다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 엔진: 차례 순환, 플레이어마다 12턴, 마지막 플레이어의 12번째 기록 뒤 게임 종료, 동점이면 같은 순위(TDD).
- [ ] 05의 시작 화면을 확장한다: 인원 1~4, 이름 입력, 기본 이름, 플레이어마다 다른 색. 1명이면 연습 모드, 2~4명이면 대전 모드로 시작한다.
- [ ] 차례 배너는 화면을 막거나 확인 버튼을 요구하지 않는다.
- [ ] 현재 차례인 플레이어의 점수표 열이 그 플레이어 색으로 강조된다.
- [ ] 결과 화면: 대전 모드면 순위, 연습 모드면 05의 최고 점수 비교. "같은 멤버로 다시"는 같은 인원·이름·색을 유지한다.
- [ ] 실제 4인 게임으로 375×667 세로 화면에서 스크롤 없이 한 화면에 들어오는지 다시 확인한다.
