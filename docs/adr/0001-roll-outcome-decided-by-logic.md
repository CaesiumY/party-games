# 굴림 결과는 게임 로직이 정하고, 3D는 연출만 한다

주사위 눈은 게임 로직의 난수로 먼저 정하고, 3D 장면은 그 결과가 위를 향하도록 멈추는 굴림 연출만 맡는다. 물리 시뮬레이션이 정하면 손맛은 진짜지만 모서리로 서는 경우의 처리, 테스트 재현, 그리고 나중에 붙일 온라인 멀티플레이에서 기기마다 결과가 어긋나는 문제가 생긴다. 로직이 정하면 점수 규칙을 3D 없이 테스트할 수 있고, 온라인 단계에서는 서버가 굴림 결과만 내려보내면 된다.

## Consequences

- 3D 쪽 코드는 굴림 결과를 입력으로 받는다. 물리 엔진을 쓰더라도 멈춘 면을 읽어 점수에 반영하는 코드를 만들지 않는다.
- 연출이 끝나기 전에도 결과는 이미 정해져 있다. 연출 건너뛰기, 접근성 모드, 테스트 자동화가 결과에 영향을 주지 않는다.
