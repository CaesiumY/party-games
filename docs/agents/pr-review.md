# PR Review Bot

이 저장소의 PR은 Codex(`chatgpt-codex-connector`)가 자동으로 검토한다.

## 언제 검토하는가

Codex는 PR을 열 때, 초안을 정식 PR로 바꿀 때, `@codex review` 댓글이 달릴 때만 검토한다. 새 커밋을 올려도 저절로 다시 검토하지 않는다.

## "봇이 통과시켰다"의 판단

- 통과 신호는 두 가지다: PR에 👍 반응, 또는 "Didn't find any major issues" 댓글.
- 그 신호가 가리키는 **검토한 커밋 해시가 PR의 최신 커밋과 같아야** 통과로 본다. 다르면 `@codex review` 댓글로 재검토를 요청한 뒤 다시 확인한다.
- `@codex review` 댓글은 공개 PR에 글을 남기는 일이라, 사용자가 요청했거나 승인했을 때만 단다.

## 예외: 봇이 사용 한도에 걸렸을 때

Codex가 검토 대신 사용 한도에 걸렸다는 댓글만 남겨 최신 커밋을 검토하지 못하면, 로컬 리뷰로 대신할 수 있다. 다음을 모두 지켜야 통과로 본다.

- **사용자가 그 PR에 대해 직접 승인한다.** 채팅에서 받아도 된다. 기준에서 벗어나는 결정이라 PR마다 따로 묻고, 한 번 받은 승인을 다른 PR에 쓰지 않는다.
- **로컬 리뷰가 수렴했다.** `/mattpocock-skills:code-review`(Standards·Spec 두 갈래)를 PR의 최신 커밋에 돌리고, 지적을 고친 뒤 다시 돌리기를 지적이 없어질 때까지 반복했다.
- **해결되지 않은 리뷰 대화가 0건이다.**
- **머지하는 커밋이 로컬 리뷰를 마친 커밋과 같다.** `gh pr merge --match-head-commit <그 커밋>`으로 머지한다.

머지한 뒤에는 봇 대신 로컬 리뷰로 머지했다는 것과 그 이유를 PR 댓글로 남긴다. 나중에 봇이 다시 검토할 수 있게 되어 그 PR에 지적을 남기면, 새 PR로 고친다.

예: PR #27(2026-10-19)은 Codex 한도에 걸려 최신 커밋을 검토받지 못했다. 로컬 리뷰를 네 바퀴 돌려 수렴시킨 뒤, 사용자 승인을 받아 머지했다.
